# Proyecto Alia

- `backend/` Node.js + Express + Sequelize (sin `uploads/` ni zips por peso)
- `appchantres/` App Flutter (frontend)

## Backend
1. Copiar `backend/.env.example` a `backend/.env` y completar valores.
2. `npm install`
3. `node server.js`

La carpeta `backend/uploads/` se ignora en git (contiene muchas imagenes locales).
